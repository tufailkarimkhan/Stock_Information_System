# Stock_Information_System
Here I will get the stock suggestion through Multiagent system, where I should invest .

Here’s the tech stack powering the agents:

🧠 OpenAI: Orchestrates the workflow and synthesizes data into clear, actionable summaries.
🔍 Tavily: Scours the web for live market news and sentiment analysis.
📊 yahoo-finance2 SDK: Fetches high-fidelity historical pricing and financial statements.

Instead of just outputting raw numbers, the system combines quantitative data with real-world context to explain why markets move. Seeing these agents collaborate seamlessly has been an amazing experience!
